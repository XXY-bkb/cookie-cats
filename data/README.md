# 数据说明

`cookie_cats.csv` 来自 Kaggle 公开数据集 **Mobile Games A/B Testing — Cookie Cats**，
本项目仅用于学习与作品展示。

- 来源页面：<https://www.kaggle.com/datasets/yufengsui/mobile-games-ab-testing>
- 字段与含义见项目根目录 `README.md` 第 2 节
- 文件校验：90,189 行 × 5 列，2,707,297 字节（CRLF 换行）

> 如果你要在公开仓库里重新分发这份数据，请先确认 Kaggle 上该数据集的许可条款；
> 更稳妥的做法是只提交下载脚本，让别人自己下载。
>
> 本项目为了让"clone 即可复现"成立，选择直接提交数据文件。
